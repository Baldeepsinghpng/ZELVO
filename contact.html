The useful bits

A few answers.

This is a static storefront preview. Here’s what is and isn’t connected yet.

Can I place a real order?

Not from this class-project preview. The bag and checkout button demonstrate the shopping flow, but no payment provider or order system is connected.

Does the contact form send an email?

No. With the included local server running, the form validates and accepts the message in server memory. It clears when you stop the server and does not send email.

Why aren’t some photos loading?

Product and editorial photography is hosted by Unsplash, so images need an internet connection. The storefront itself runs locally.
